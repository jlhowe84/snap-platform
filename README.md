# SNAP Photo Day Platform

The operating system for SNAP Photo's sports photo days: leagues, booking,
planning, rosters, scheduling, crew, support, production and the owner view,
with an AI agent working through the same action layer as every screen.

The plan and spec live outside this repo (the SNAP OS repository,
`snap-os/60-projects/photo-day-platform/spec-2026-11.md`). Work arrives here
through pull requests.
